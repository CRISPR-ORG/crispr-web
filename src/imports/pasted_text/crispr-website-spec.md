# CRISPR IIIT NAGPUR

## Official Website — Complete Design & Development Specification

You are an expert product designer, creative frontend engineer and interaction designer.

Your task is to build the **official website of CRISPR Club, IIIT Nagpur** from scratch.

This is an established technology and innovation club.

This is NOT a recruitment website.

This is NOT a college admission website.

This is NOT a generic startup landing page.

This website should feel like it was created by a group of serious developers who happen to have an exceptional sense of design.

---

# 01 — DESIGN REFERENCE

Study these two websites before writing the UI:

CRISPR reference:

https://crisprjoin.vercel.app/

IIIT Nagpur reference:

https://elevate-black-two.vercel.app/

The first reference is especially important for understanding the desired:

* visual polish
* developer aesthetic
* typography
* interactions
* layout confidence
* dark interface
* technical personality
* overall "coding website" feeling

The second reference is useful for understanding:

* IIIT Nagpur's visual ecosystem
* institutional quality
* navigation
* spacing
* responsiveness

DO NOT copy either website.

Use them only to understand the quality bar.

The CRISPR website must have its own identity.

# 02 — THE CORE IDEA

The entire website should feel like:

# A WEBSITE BUILT BY DEVELOPERS.

When someone opens it, they should immediately recognize:

* code
* engineering
* software
* systems
* repositories
* terminal
* open source
* experimentation
* developers
* products
* AI
* campus technology

The design language should come from the **developer world**.

Not from biology.

Not from corporate websites.

Not from generic startup templates.

CRISPR is a technology club.

The interface should communicate that.

# 47 — DESIGN QUALITY CHECK

Before completing the project, inspect every page.

Ask:

### Does this look like a developer designed it?

### Does it feel like CRISPR?

### Does the green feel natural rather than neon?

### Does it feel connected to IIIT Nagpur?

### Does it feel polished enough to be shown to recruiters, alumni and college administration?

### Does the Team hierarchy immediately make sense?

### Are Lead and Co-Lead clearly the highest level?

### Is Head of Development directly below them?

### Are the remaining heads below that?

### Are photographs treated as important visual elements?

### Are the animations subtle?

### Does the site look good without animations?

If any answer is NO, improve the design before finishing.
